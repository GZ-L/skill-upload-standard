# Notice

This repository defines a documentation and validation standard for uploading Codex / Agent Skills to GitHub.

## Source

- Maintainer: `GZ-L`
- Source type: original workflow standard
- Upstream source: none

This repository does not include third-party source code, binaries, datasets, private account data, or generated assets.

## Purpose

The files in this repository are intended to help future Skill upload workflows produce clear documentation, source disclosure, installation instructions, usage examples, validation notes, and licensing boundaries.

## Redistribution Boundary

When this standard is used for a different Skill, the uploaded Skill must document its own source, ownership, license, and redistribution boundary. Do not assume this repository's source status applies to other Skill packages.
